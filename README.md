# 🦷 Pure Smile

Sistema de Gerenciamento para Clínica Odontológica desenvolvido como projeto acadêmico do curso de Desenvolvimento de Sistemas.

## 📋 Sobre o Projeto

O **Pure Smile** é uma aplicação desenvolvida para auxiliar no gerenciamento de clínicas odontológicas, permitindo o controle de pacientes, consultas, procedimentos odontológicos, pagamentos e perfis de usuários.

O sistema foi projetado para centralizar as informações da clínica em uma única plataforma, proporcionando mais organização, eficiência e praticidade no atendimento.

## 🎯 Missão do Sistema

Oferecer uma solução moderna, intuitiva e eficiente para a gestão de clínicas odontológicas, contribuindo para uma melhor experiência tanto para os profissionais quanto para os pacientes.
